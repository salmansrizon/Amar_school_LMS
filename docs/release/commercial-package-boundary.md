# First Commercial Package Boundary

Conservative launch proposal for owner approval. It sells the product that is
already usable without promising unresolved gateway, tax, or tender features.

## Included

- School Owner and Staff access with tenant and class/subject authorization.
- Student portal reads and request workflows.
- Student, employee, class, attendance, examination, fee, notice, question,
  institute setup, SMS composition, and existing reporting surfaces.
- Manual invoice/payment recording with the provider-neutral payment lifecycle
  available for integration, but no live gateway claim.
- Bangla-first and English UI, browser print flows, audit events, and support
  through an agreed service channel.

## Explicitly Deferred

- Real gateway/bank adapters and provider certification.
- Legally approved VAT invoice, credit/debit note, refund, and reconciliation
  workflows.
- Buyer-specific government dashboards, SLA, hosting/data-residency promises,
  accessibility acceptance, training, warranty, and exit obligations.
- Any module that fails the release matrix or has an open Blocker/Major finding.

## Approval Record

This proposal becomes the first package only after the owner records the target
customer, included roles/modules, payment mode, support promise, languages,
price basis, and deferred features in map #554. Until then its status is
PROPOSED, not a product or tender claim.
