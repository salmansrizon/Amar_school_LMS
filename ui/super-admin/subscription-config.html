ফি সূত্রFee Formula

মাসিক বিল = বেস প্ল্যাটফর্ম ফি + (শিক্ষার্থী সংখ্যা × প্রতি শিক্ষার্থী হার) Monthly bill = Base Platform Fee + (Student Count × Per-Student Rate)

এই হার পরিবর্তন করলে তা শুধুমাত্র ভবিষ্যতের বিলিং সাইকেলে প্রযোজ্য হবে। পূর্ববর্তী বিল পুনরায় হিসাব করা হবে না। পরিবর্তনের পূর্বের মান নিচের ইতিহাস টেবিলে সংরক্ষিত থাকবে। Changing this rate only applies to future billing cycles. Past bills are not recalculated. The prior value is preserved in the rate history table below.
